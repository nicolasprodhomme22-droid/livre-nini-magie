# Règle : Utilisation de sources_lisibles

Lors de toute interaction, lecture, extraction ou recherche concernant les documents PDF de ce projet :
1. **Tu dois toujours utiliser** le chemin `Sources/sources_lisibles`.
2. Ce dossier contient les versions OCRisées et certifiées lisibles des livres de magie.
3. Ne va **jamais** chercher les PDF dans le dossier `Sources` d'origine, car ils peuvent contenir des images brutes inexploitables.
